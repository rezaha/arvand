# اینترانت پتروشیمی اروند

## اجرای سایت سالم با قالب جدید

آدرس سالم اعلام‌شده، `http://localhost:8135/fa-IR/AR/default`، مربوط به سایت **IntranetAdmin** است. قالب اکنون در صفحهٔ نخست همین سایت نصب شده است. تنظیمات اتصال، مسیریابی و DLLهای آن تغییر نکرده‌اند.

پس از دریافت `main`، فایل **`Open-Arvand.cmd`** را باز کنید؛ در Visual Studio روی **IntranetAdmin** راست‌کلیک، **Set as StartUp Project** را انتخاب و Ctrl+F5 بزنید. همان آدرس پورت **8135** را باز کنید.

این مسیر به **.NET Framework 4.8 و محیط پایگاه دادهٔ سالم قبلی** نیاز دارد. نیازی به تغییر رمز، کپی Web.config سایت دیگر یا اجرای پیش‌نمایش برای نصب قالب نیست.

[تفاوت دو سایت، راهنمای دقیق اجرا و نتیجهٔ بررسی‌ها](docs/working-site-8135.md)

## دیدن طراحی در Visual Studio

۱. آخرین نسخهٔ شاخهٔ `main` را دریافت کنید.

۲. Visual Studio 2022 نسخهٔ 17.8 یا جدیدتر را با گزینهٔ **ASP.NET and web development** و **.NET 8 SDK** نصب کنید.

۳. فایل **`ArvandPreview.sln`** را از ریشهٔ مخزن باز کنید.

۴. پروژهٔ `Arvand.Preview` را انتخاب و **F5** یا **Ctrl+F5** بزنید. مرورگر به‌صورت خودکار باز می‌شود. پروفایل اجرا روی پورت ۵۱۷۸ تنظیم شده است؛ اگر پورت اشغال بود، مقدار `applicationUrl` در `preview/Arvand.Preview/Properties/launchSettings.json` را تغییر دهید.

این پیش‌نمایش بدون Python، SQL Server، IIS Express یا احراز هویت دامنه اجرا می‌شود. قالب‌ها، CSS، فونت، لوگو و تصاویر همان فایل‌های صفحهٔ اصلی هستند؛ دادهٔ آزمایشی نیز با پیش‌نمایش Python مشترک است. لینک‌های مقصد، صفحهٔ توضیح پیش‌نمایش را باز می‌کنند؛ جستجوی واقعی، ورود و دانلود اسناد به سامانهٔ اصلی نیاز دارند.

اجرای معادل با ترمینال، از پوشهٔ اصلی مخزن:

```powershell
dotnet run --project preview/Arvand.Preview/Arvand.Preview.csproj
```

## اجرای سامانهٔ اصلی

فایل `ArvandIntranet/ArvandIntranet.sln` مربوط به سامانهٔ واقعی Web Forms با .NET Framework 4.8 است. این مسیر همچنان به Windows/IIS، کتابخانه‌های قدیمی و پایگاه دادهٔ موجود سامانه نیاز دارد. پیش‌نمایش بالا این وابستگی‌ها را برای سامانهٔ واقعی حذف نمی‌کند.
