# تکمیل قابلیت‌های پروژهٔ اصلی در سایت با تم جدید

مبنا همان سایت سالم `IntranetAdmin` روی پورت 8135 است. این تغییر فایل اتصال، مسیریابی، صفحهٔ نخست و CSS تأییدشده را عوض نمی‌کند. صرف وجود فایل و مسیر برای برابری عملکرد کافی نبود؛ تفاوت‌های واقعی کد نیز بررسی شدند.

| قابلیت | نتیجهٔ انتقال و اصلاح |
| --- | --- |
| صفحه‌های اصلی، فرم‌ها و سرویس‌ها | مسیرها و صفحه‌های عمومی قبلاً منتقل شده‌اند؛ ثبت مسیرها و عملیات سرویس همچنان بررسی می‌شوند. فرم‌های خبر، تماس، نظر، نظرسنجی و تعاونی از کدهای اصلی استفاده می‌کنند. |
| منوهای چندسطحی | داشتن لینک روی منوی والد دیگر زیرمنوها را پنهان نمی‌کند. داخل پنجرهٔ منو، هم لینک خود والد و هم فرزندان قابل دسترسی‌اند. |
| لینک‌های منو | شناسهٔ عددی قدیمی، مسیر `ShowPage/id/title`، صفحهٔ عادی و URL بیرونی تفکیک می‌شوند؛ کل مسیر چندبخشی داخل پارامتر pageName قرار نمی‌گیرد. |
| انتخاب صفحه در مدیریت منو | منطق اصلی انتخاب صفحه و ارتباط با واحد دوباره استفاده شده و انتخاب‌گر ارتباط با واحد نیز در دسترس است. |
| وب‌پارت‌های قابل تنظیم | مسیر جدید `PortalWidgets` با کلاس اصلی Container، همان تنظیمات `Default.aspx`، کنترل‌ها و بررسی مجوزهای قبلی را بارگیری می‌کند. از «امور»، «نقشه سایت» و حساب کاربری به «بخش‌های سازمانی و وب‌پارت‌ها» دسترسی دارید. چیدمان ثابت صفحهٔ نخست حفظ می‌شود؛ تنظیم وب‌پارت‌ها در این مسیر دیده می‌شود. |
| مدیریت | ورود به بخش مدیریت از حساب کاربری و نقشه سایت در دسترس است. منوی مدیریت و نمایش گزینه‌ها طبق مجوزهای اصلی برگردانده شده‌اند. زمان نشست و گزینهٔ Remember نسخهٔ سالم حفظ شده‌اند. |
| رمز شخصی | کاربر دارای حساب مدیریت معتبر برای تغییر رمز خودش به مجوز فرم اضافی نیاز ندارد؛ handler همان کاربر جاری و رمز قبلی را بررسی می‌کند. سایر فرم‌ها همچنان مجوز خود را لازم دارند. |
| تاریخچه | فراخوانی ثبت تاریخچهٔ عملیات مدیریت که غیرفعال شده بود دوباره فعال است. |
| تعاونی و Excel | ستون محل تعاونی و دکمهٔ دریافت Excel برگشتند. خروجی به مجوز Print وابسته است؛ فایل واقعی XLSX با هر ۱۲ ستون اصلی، نمایش راست‌به‌چپ و مقادیر متنی تولید می‌شود. از ZIP/XML خود Framework استفاده می‌شود و EPPlus یا Office Interop لازم نیست. قالب‌بندی فعلی از فونت Tahoma استفاده می‌کند. |
| دریافت اسناد | هدر نادرست شامل دو عبارت filename اصلاح شد؛ نام‌های فارسی از همان helper اصلی استفاده می‌کنند. بررسی مجوز و مسیر فایلِ handler قبلی حفظ شده است. |

## بررسی‌های انجام‌شده

- کد مشترک، handler دانلود، صفحه‌های عمومی و صفحه‌های مدیریتِ تغییرکرده با DLLهای واقعی سایت و reference assemblyهای Framework 4.8 کامپایل شدند. اعلان فیلدهای تولیدشوندهٔ markup فقط در harness بررسی ساخته شد.
- ۲۵ آزمون روی کد واقعی helper نشانی، هدر دانلود و اجزای XLSX اجرا می‌شوند؛ PDF به‌صورت inline و فایل دریافت‌شدنی به‌صورت attachment با نام ASCII و فارسی بررسی شده‌اند. فایل XLSX نیز با خوانشگر مستقل openpyxl باز و دادهٔ فارسی، صفرهای ابتدای کدها و نمایش راست‌به‌چپ تأیید شد.
- آزمون مرورگر، منوی والد دارای لینک، زیرمنوی چندسطحی، باقی ماندن لینک والد، دسترسی به وب‌پارت‌ها و مدیریت، جستجو، دیالوگ‌ها و نمای واکنش‌گرا را بررسی می‌کند.
- اسکریپت پوشش مسیرها حضور ۱۹ ثبت مسیر، ۷۹ فایل ASPX، ۹ عملیات سرویس و وابستگی‌های صفحه‌ها را کنترل می‌کند.
- فایل‌های تنظیمات سایت سالم و قالب تأییدشده با نسخهٔ پیش از تغییر مقایسه شده‌اند.

## بررسی زندهٔ باقی‌مانده

این محیط به IIS ویندوز و SQL Server سیستم کاربر دسترسی ندارد. موفق بودن کامپایل و مرورگر به معنی تأیید ثبت واقعی فرم‌ها، نگهداری نشست، همهٔ مجوزها، ثبت تاریخچه یا دانلود واقعی Excel در آن محیط نیست. پس از pull، در همان محیط توسعهٔ سالم بررسی کنید:

۱. ورود مدیریت، نمایش منو با حساب مدیر و حساب دارای دسترسی محدود، و تغییر رمز خود کاربر.

۲. انتخاب صفحه در مدیریت منو و باز شدن همان لینک و زیرمنو از صفحهٔ نخست.

۳. وب‌پارت‌های تنظیم‌شدهٔ واحد در «بخش‌های سازمانی و وب‌پارت‌ها».

۴. ثبت و ویرایش فرم‌ها و ظاهر شدن رویداد در تاریخچه.

۵. فایل عمومی/خصوصی، PDF و نام فارسی؛ دریافت Excel تعاونی با حساب دارای مجوز Print.

برابری کامل همهٔ قواعد کسب‌وکار تا این بررسی‌های زنده تأیید نشده است.
