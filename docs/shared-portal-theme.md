# قالب مشترک سایت اروند

صفحهٔ خبر، از جمله `/fa-IR/AR/ShowNews/390`، و دیگر صفحه‌های HTML از `MasterPages/PortalShell.master` استفاده می‌کنند. سربرگ، منوی راست، جستجو، فونت، پیوندهای ویژه و پابرگ با صفحهٔ نخست مشترک‌اند. قالب‌های قبلی به واسط همین پوسته تبدیل شده‌اند و انتخاب Theme قدیمی از دیتابیس دیگر ظاهر را عوض نمی‌کند. پوستهٔ مدیریت، شناسهٔ کنترل‌ها و پالایش منو بر اساس مجوز قبلی را حفظ می‌کند.

۱۸ کارت مرجع همیشه در صفحهٔ نخست دیده می‌شوند؛ کارت بدون نشانی، پیام نبودن پیوند را باز می‌کند. سامانه‌های فعالِ اضافی نیز نمایش داده می‌شوند و دو پیوند برجستهٔ برید و مدیریت فناوری اطلاعات باقی مانده‌اند. ۲۰ گزینهٔ منوی مرجع، زیرمنوهای ثبت‌شده و پیوندهای بخش‌های سازمانی، نرخ ارز، تعاونی مسکن، آرشیو اخبار، ارتباط و مدیریت در دسترس‌اند.

نقطه‌های اسلایدر حذف شده‌اند؛ جابه‌جایی اسلاید با دو دکمهٔ دایره‌ای و شیشه‌ای انجام می‌شود. متن انگلیسی، عنوان، زیرعنوان و دکمهٔ اسلایدر هم‌ترازند و کنترل‌ها با فاصلهٔ بیشتر زیر آن‌ها قرار دارند. کارت‌های میانی زمینه و سایه ندارند؛ حاشیهٔ یک‌پیکسلی و حرکت ملایم هنگام هاور دارند. در تنظیم کاهش حرکت مرورگر، این حرکت غیرفعال می‌شود. استایل عمومی فرم‌های داخلی روی اجزای صفحهٔ نخست اعمال نمی‌شود.

نرخ ارز در پایین منوی راست و در `/fa-IR/AR/Currency` قرار دارد. سرویس JSON جدید `api/Service/PortalRates/fa/0` از همان خوراک بانک ملیِ پروژه استفاده می‌کند. قیمت و تاریخ از منبع دریافت می‌شوند؛ قطع سرویس با پیام روشن و دکمهٔ تلاش مجدد نمایش داده می‌شود. محدودیت زمان دریافت و منع DTD اعمال شده است. دسترسی فعلی بانک ملی و تازه‌بودن اطلاعات آن از این محیط تأیید نشده‌اند؛ اعداد نمونهٔ آزمون وارد سایت اصلی نشده‌اند.

RSS، تصویر امنیتی، دانلود و خروجی‌های PDF/Word محتوای خروجی قبلی خود را حفظ می‌کنند؛ پوستهٔ HTML به فایل دریافتی اضافه نمی‌شود. تنظیمات Web.config، اتصال SQL Server، مسیرهای Global.asax و DLLها در این تغییر عوض نشده‌اند.

## بررسی انجام‌شده

- زنجیرهٔ قالب هر ۷۸ صفحهٔ HTML در هر دو سایت بررسی شد؛ جای‌نگهدارهای محتوا به قالب والد متصل‌اند و فرم تودرتو ایجاد نشده است.
- کد واقعی App_Code، صفحه‌های عمومی، کنترل‌ها و پوستهٔ جدید با مراجع .NET Framework 4.8 کامپایل شد؛ کنترل‌های مدیریتِ پوشش‌داده‌شده نیز بررسی شدند.
- آزمون Chromium کارت‌ها، زیرمنوها، تصاویر، جستجو، صفحهٔ خبر در عرض‌های ۱۴۲۸، ۱۰۲۴، ۷۶۰ و ۳۹۰ پیکسل و دریافت/قطع نرخ ارز با دادهٔ آزمایشی را پوشش می‌دهد.
- پروژهٔ مستقل پیش‌نمایش .NET 8 نیز ساخته شد. مسیرهای `news.html` و `currency.html` برای بازبینی طراحی به آن اضافه شدند.

اجرای IIS با دیتابیس سازمانی، ورود مدیریت، ثبت فرم و دریافت واقعی دادهٔ خبر ۳۹۰ در این محیط لینوکسی انجام نشده‌اند. تصاویر بازبینی دادهٔ نمونه دارند.

## اجرای نسخهٔ اصلی پس از دریافت

در پوشهٔ کلون‌شده `git pull --ff-only origin main` را اجرا کنید. سپس `ArvandIntranet/ArvandIntranet.sln` را در Visual Studio باز کنید، `IntranetAdmin` را Startup Project بگذارید و Rebuild و Ctrl+F5 بزنید. صفحهٔ نخست و نشانی خبر بالا را باز و با Ctrl+F5 مرورگر فایل‌های تازه را دریافت کنید. از همان تنظیمات سالم محلی پایگاه داده استفاده کنید.

برای بررسی طراحی در محیط توسعه:

```bash
python3 tools/check_route_coverage.py
python3 tools/check_portal_shell.py
python3 tools/preview_portal.py --site IntranetAdmin --output /tmp/arvand-portal-preview
python3 -m http.server 8765 --directory /tmp/arvand-portal-preview
# در ترمینال جداگانه، با Playwright و Chromium نصب‌شده:
PORTAL_PREVIEW_URL=http://127.0.0.1:8765 node tools/check_portal.cjs
PORTAL_PREVIEW_URL=http://127.0.0.1:8765 node tools/check_portal_inner.cjs
```
